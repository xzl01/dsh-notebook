# dsh-notebook

把 DeepSeek Harness Web UI 当作一个 Notion 式的笔记本：打开就是渲染好的页面，点哪里就能改哪里，
没有「编辑 / 预览」模式切换。笔记来自一个 Obsidian 仓库目录（只当作磁盘上的 Markdown 文件夹），
但在 DSH 内渲染和编辑，不打开、不嵌入 Obsidian；对话中的 Agent 也能读写同一批笔记。

## 编辑方式

### 文本与格式

- 打开笔记即是渲染后的页面：标题、段落、列表、待办、引用、代码、分隔线都按样式显示。
- **点击任意块**即可在原位编辑；编辑时块内格式（**加粗**、*斜体*、`行内代码`、~~删除线~~、链接）
  直接以样式显示，不再看到 Markdown 标记；输入 `**文字**`、`*文字*`、`` `文字` ``、`~~文字~~`
  时**闭合标记一敲下就变样式**。失焦后回到渲染态并自动保存（停止输入约 1 秒）。
- `Ctrl/Cmd+B` 加粗、`Ctrl/Cmd+I` 斜体；选中文字浮出格式工具栏（加粗 / 斜体 / 删除线 /
  行内代码 / 链接 / 清除格式），点按钮不会丢失选区。
- **跨段落选择**也支持：工具栏照常出现，格式化会逐块套 Markdown 标记（不会重写整篇）；
  清除格式会逐块去掉选区周围或内部的粗体/斜体/删除线/行内代码/链接标记；
  按 `Backspace` / `Delete` 删除选区：完全覆盖的块整块删掉，只覆盖一部分的边缘块只删选中的文字
  （全删时留一个空段落）。
- `Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 或 `Ctrl+Y` 重做（连续输入合并成一步）。
- `Ctrl/Cmd + =` / `Ctrl/Cmd + -` 快速增减正文字号。
- `Ctrl/Cmd+F` 页面内查找：输入关键词实时显示命中块数，`Enter` / `Shift+Enter` 上下跳转，
  跳转目标块会短暂高亮；`Esc` 关闭。
- 点击正文里的链接弹出编辑条：改地址、打开、移除链接（保留文字）。
- `[[笔记名]]` 会渲染成可点击链接，点击直接打开对应笔记（按名称或路径匹配，找不到会在顶部提示）；
  `[[笔记名#标题]]` 会打开笔记并滚动到该标题；反向链接与出链见下方「双向链接」一节。
- `![[笔记名]]` 形式的**嵌入引用**会在当前块内渲染那篇笔记的只读内容（标题、列表、引用、代码等），
  超过 12 块折叠成「展开全部」、展开后可再「收起」；点嵌入区标题可直接打开原笔记；嵌套深度最多两层。
- **块 / 章节嵌入**：`![[笔记名#^块id]]` 只渲染被锚定的那一个块（改源块，所有引用处一起变，
  等价于 Notion 的同步块）；`![[笔记名#标题]]` 渲染该标题到下一个同级标题之间的整节；
  块菜单的「复制块嵌入」会直接复制 `![[笔记#^id]]`（没有 id 时自动生成）。

### 块与结构

- **页面模板按钮**：斜杠菜单 →「模板按钮」插入一个虚线按钮（存为 `[新建页面](nb://template)`），
  点击后选模板即可当场以该模板**创建子页面**（自动写入 `parent`，进入侧栏树）。
- **Emoji 短代码**：输入 `:smile:`、`:rocket:`、`:tada:` 等 50+ 个短代码，闭合冒号时立即变成对应 emoji
  （纯文本块内生效，不影响行内格式）。
- 输入 Markdown 语法即时变块类型：`# ` `## ` `### ` 标题、`- ` 列表、`1. ` 编号、`- [ ]` 待办、
  `> ` 引用、``` 代码、`---` 分隔线。
- 输入 `/` 打开插入菜单，继续输入按名称或别名过滤（`/h2`、`/todo`、`/代码`、`/list`…），
  `Enter` 选第一项、`Esc` 关闭。
- `Enter` 拆分块；空标题 / 空列表按 `Enter` 回到正文；`Shift+Enter` 块内换行；
  空块 `Backspace` 先回到正文（正文空块再退格合并到上一块），`Esc` 退出编辑。
- 悬停块左侧出现 `+`（在其后插入一块）和 `⋮⋮`：按住 `⋮⋮` 拖动调整顺序（带幽灵预览、边缘自动滚动），
  单击打开块菜单；悬停块**右侧**出现 `⋯`，同样打开块菜单（改类型、上移 / 下移、**转为子页面**、
  **复制块链接**、删除）；触摸屏长按块也能打开菜单。双击块直接进入编辑。
- **块级锚点引用**：「复制块链接」会给块生成稳定 id（写回 Markdown 行尾 ` ^id`）并复制
  `[[笔记#^id]]`，粘贴到别处点击即可跳转到那一段；已有 id 的块直接复用。
- 「转为子页面」把该块的内容变成同目录下的一篇新笔记，原位置留下 `[[标题]]` 链接（Notion 的页面嵌套）。
- 列表 / 待办 / 段落 / 引用支持**缩进层级**：块内按 `Tab` 加深、`Shift+Tab` 减浅（最多 3 级），
  序列化为两个空格一层，可与其他 Markdown 编辑器互认；代码块内 `Tab` 插入两个空格。
- 标题左侧 `▾ / ▸` 折叠该标题下内容，直到下一个同级或更高级标题。
- `/callout` 或 `> [!note] 内容` 得到**提示块**：按类型着色（note/info 蓝、tip/abstract 青、
  warning 琥珀、danger/bug/failure 红、success/todo 绿、question/important 紫、quote 灰、
  example 靛），背景是 10% 色调混入当前主题表面，深色主题自动成立；**点左侧图标可在
  9 种类型间循环切换**（阅读模式下不可点），图标也会跟着变。`[!toggle]` 仍是折叠块。
- `/toggle` 或 `> [!toggle] 标题` 得到**折叠列表**：下面缩进的块是内容，点箭头收起/展开，
  收起状态写回 `> [!toggle]-`，重开笔记仍保持。
- **代码块**：悬停右上角语言标签切换语言（`js`、`python`、`shell`、`toml`…），保存为 ```lang 围栏；
  失焦后按语言着色——注释、字符串、数字、关键字之外，函数名、类型、键名、标签/属性、变量、小节标题各有颜色。
  支持 JS/TS、Python、Shell、JSON、YAML、INI/TOML/desktop、HTML/Vue、CSS/SCSS、SQL、C 系/Go/Rust/Java/C#、
  Markdown、Dockerfile；未标注或未知语言保持纯文本，不会乱上色。
- **表格**：`/table` 插入或粘贴 Markdown 表格自动识别（保留 `:---:` / `---:` / `:---:` 对齐）；
  单元格点选即编辑，`Tab` / `Shift+Tab` 跳格、`Enter` 下移、`Shift+Enter` 单元格内换行
  （存成 `<br>`，Obsidian 里也能正常显示）；悬停出现 `+ 行 / + 列 / - 行 / - 列`；
  行左侧 `⋮⋮` 拖动调整行顺序、表头左侧 `⋮⋮` 拖动调整列顺序（对齐一起移动）；
  表头右边界拖拽条调整列宽（按笔记记住，不写进 Markdown）。
- **图片**：粘贴截图、把图片拖进编辑块或拖到页面任意位置，存进笔记库 `附件/`（`attachmentDir` 可配），
  写入 `![](附件/xxx.png)` 并直接显示；斜杠菜单「图片」可输入 URL 插入；点击图片弹出控制条改 alt、
  按 `25% / 50% / 75% / 100%` 设宽度（写回 `{width=50%}`）、移除图片。
- 粘贴多行 Markdown 会按块解析并插入，而不是挤进一行。

### Marp 幻灯片

代码块里的内容是 Marp 幻灯片时（开头 YAML 里 `marp: true`——全角冒号也认，或者围栏语言写 `marp`），
默认渲染成 16:9 幻灯片：块左上角有 `MARP` 标记和「幻灯片 / Markdown」切换，下方有 ‹ › 与页码，
方向键（← →）也能翻页；点卡片不会误进编辑，要改源就切到 Markdown 再点。

渲染覆盖常用语法：`---` 分页、标题、列表、表格、引用、代码块、粗斜体/行内代码/链接。
Marp 的模板 class、`<!-- fit -->`、导出 PPTX 尚未实现——需要的话可以按 Marp CLI 的语义再补。

### 多选与移动

- **Shift+点击**另一个块可多选（选区变灰），`Backspace` / `Delete` 批量删除，
  `Ctrl/Cmd+C` 复制、`Ctrl/Cmd+X` 剪切，`Esc` 取消；按住任一选中块的 `⋮⋮` 拖动可**整组移动**。

### 组织与导航

- **面包屑**：正文顶部显示 `笔记库 / 目录 / 当前页`，点目录直接展开侧栏对应分组（禅模式自动隐藏）。
- **子页面树**：用块菜单「转为子页面」创建的子笔记会在 frontmatter 写入 `parent`，侧栏里按父子关系
  嵌套缩进显示（父页 → 子页 → 孙页），不再是平铺列表。

- **编辑时右侧悬浮大纲**：进入任意块的编辑状态后，右上角浮出当前笔记的大纲（标题层级缩进、
  当前章节高亮），点一下即可跳转；退出编辑自动隐藏，窄屏不显示。
- **收藏与最近打开**：右键笔记可「收藏」，侧栏顶部列出收藏（★）和最近打开的 5 篇（⟲），点一下即跳转。
- **命令面板（Ctrl/Cmd + P 或 K）**：同一个居中面板里，先列出动作（新建笔记、问 AI、禅模式、
  阅读模式、宽/窄版、页面属性、版本历史、关系图谱、快捷键、导出 Markdown），再列出匹配的笔记；
  `↑` / `↓` 选择、`Enter` 执行或打开、`Esc` 关闭。
- 左侧栏：搜索（命中词高亮；结果分成「标题匹配」和「正文匹配」两组，正文命中带行号、每篇最多列 3 条，
  「还有 N 处」折叠；点正文命中会打开笔记并滚到对应块、短暂高亮）、新建笔记/新建文件夹、按目录分组的笔记列表（目录可折叠；右键笔记可
  收藏、重命名、**移动到…**、复制路径、删除；**把笔记拖到目录标题上即可移动**）；当前目录跟随打开的笔记展开。
  侧栏不再显示大纲（避免与笔记列表挤在一起），大纲只在编辑时以右侧悬浮卡片出现。
- 文件夹支持**任意层级**：新建时直接写 `a/b/c`，侧栏按父子缩进成树；折叠父文件夹会一起收起子层级，
  空文件夹也会显示（可拖笔记进去）；打开笔记会自动展开它所在的整条路径。
- **文件夹主页**：在文件夹里放一篇同名的 md（`01 工作/工作.md`，或去掉序号前缀的 `工作.md`，
  `index.md` 兜底），点文件夹名字就直接打开它；`▸`/`▾` 仍负责展开收起。右键文件夹有
  「新建/打开文件夹主页」，不存在时一次点出这篇笔记。
- 打开的笔记在顶部形成**标签页**，点击切换、`×` 关闭；刷新后标签组会恢复。
- 触摸屏上左右滑动正文可切换相邻标签页。
- 每篇笔记会**记住自己的滚动位置**，切回来接着看。
- 打开插件时自动恢复上次编辑的笔记。

### 页面设置

- 页面标题可直接点击修改（等于重命名文件）。
- 标题上方可加 **emoji 图标**与**封面**（图片 URL 或笔记库相对路径），分别存在 frontmatter 的
  `icon` / `cover` 字段，Obsidian 也能看到；原有 frontmatter 其他字段保持不变。
- **禅模式（Zen）**：`Ctrl/Cmd + Shift + F` 或顶栏 `◨` / `⋯` 菜单进入。侧栏、顶栏、图标与封面、
  块把手、添加按钮、页底链接区全部隐藏，连宿主 DSH 的侧栏也会自动收起，只留正文和光标；
  右上角半透明的「退出禅模式」按钮或 `Esc` 退出（退出后恢复此前收起的侧栏）。
- `⇤ / ⇥` 切换默认 / 全宽排版。
- `⋯` 菜单：更换图标、加/移除封面、导出、版本历史、快捷键、字号、阅读模式、删除笔记。
  **阅读模式**隐藏块把手、添加提示和悬停底色，只留正文（状态记住）。
- **在对话里打开笔记本**：聊天输入框左侧的笔记本图标，点开可选「打开笔记本」、
  「问 AI（当前笔记）」或「插入当前笔记」（把当前笔记的路径插入输入框，接着就能让
  Agent 改它）；菜单挂在 body 上，不会被输入框裁掉。
- 左侧「新建笔记」先选**模板**：内置空白 / 会议记录 / 今日记录 / 项目计划 / 读书笔记，
  另外会把笔记库 `模板/` 目录（可用 `templateDir` 配置）里的笔记列为**自定义模板**
  （选中即用其内容建新笔记）；
  新建后自动聚焦标题并全选，直接输入即可改名。

### 导出与历史

- `⋯` 菜单可**导出**当前笔记为 Markdown、独立 HTML 或直接**打印 / 存为 PDF**（打印样式只输出正文，
  隐藏侧栏、块把手等界面元素）。
- `⋯` →「版本历史」查看每次保存留下的快照（保留最近 20 个），预览显示**与当前内容的行级差异**
  （红色 = 恢复后消失，绿色 = 恢复后加回；只展开改动附近 3 行，其余折叠成「… N 行未改动」），
  可一键恢复；快照存在笔记库 `.dsh-notebook-history/`（隐藏目录，Obsidian 与列表都看不到）。
- `⋯` →「页面属性」编辑 frontmatter 的 **tags / aliases**：标签以 chip 形式展示，回车添加、点 × 删除、
  退格删最后一个（写入 `tags: [...]`）；aliases 逗号分隔；下方列出其余字段（可逐行编辑，
  清空即删除该字段），也可**新增字段**（字段名限字母/数字/下划线/短横线）；YAML 多行 / 嵌套值
  以只读形式展示（避免误改破坏结构）；面板顶部可换图标、
  加/移除封面；其他 frontmatter 字段保存时原样保留。
- `⋯` →「快捷键」查看全部快捷键。

## 写作热力（会同步）

写作统计保存在笔记库的 `统计/写作热力.json`（普通目录，不是隐藏目录），因此会随同步一起到其他设备；
旧版本放在 `.dsh-notebook/writing.json` 的数据会在首次加载时自动迁移过来。

## 双栏 / 三栏（obsidian-columns 语法）

笔记里用 `> [!col]` 分栏，空 `>` 或嵌套 `>> [!col-md]` 分隔列；列宽用 `>> [!col-md-2]`
（数字即宽度份数，默认 1）。DSH 面板与 Obsidian（安装 obsidian-columns 插件后）都能渲染。
DSH 里也可以输入 `/` 选「2 栏 / 3 栏」插入。

## Obsidian Canvas（.canvas）

- 侧栏里 `.canvas` 文件与笔记并列显示，点击打开
- 只读画布渲染：文本卡片、文件卡片（点击打开对应笔记）、链接卡片、分组框（虚线 + 标签）、
  节点颜色（颜色 1–6）、节点间连线（SVG）
- 支持缩放（+ / − 按钮）；只读预览，编辑仍在 Obsidian 中进行
- Host 接口：`GET /api/canvases`（列出画布）、`GET /api/canvas?path=`（读取并归一化节点/连线）

## 与 DSH 的原生集成

- **对话回答 → 闪念**：assistant 消息动作行新增 ⚡「存到闪念」，一键把这条回答存进逐日闪念收件箱
  （通过 `conversation.chat.assistant-actions` 槽位 + Client `sessions` 读取消息文本）
- **Mermaid 跟随主题**：DSH 切换深浅色/主题时，图表会用新主题 token 重新渲染
- 其他已有集成：面板槽位、`/note` 命令、`systemPrompt` 当前笔记、`conversation.input.left` 按钮、
  Agent 工具（list/read/search/write/flash/sync）、工具卡片视图

## Obsidian 语法兼容

面板里的渲染器对齐 Obsidian 阅读模式的核心语法：

- **内联 HTML**：白名单标签（div/span/table/details/kbd/iframe/img/video/audio/figure/mark/u 等）直接渲染，
  `script`、`on*=`、`javascript:` 一律转义
- **数学公式**：`$...$` 行内与 `$$...$$` 块级（内置精简 LaTeX：上下标、`\frac`、`\sqrt`、希腊字母与常用符号）
- **高亮** `==文字==`、**注释** `%%文字%%`（隐藏）、**标签** `#标签`（chip）、**脚注** `[^1]` + `[^1]: …`（收拢到文末）
- **Bases 视图**：`.base` YAML 子集在面板里直接渲染成表格/卡片/列表/看板（详见集合视图一节）；
  全库数据在 2 秒内共享一次加载，同一页打开多个视图不会重复拉取
- **Mermaid**：```mermaid 代码块在面板里直接渲染成 SVG 图表——Host 首次按需下载
  mermaid 运行库（固定版本，缓存到 `.dsh-notebook/vendor/`，隐藏目录不参与同步），之后离线可用；
  渲染失败时回退为卡片 + 源码

## 主页（仪表盘）

插件不自带 API key、不新增 provider 配置——所有 AI 调用都走 Harness 自己的模型服务：
Host 通过 `ctx.llm` 与 `agentDefaultModel` 解析当前默认模型（没有默认时回退到第一个可用 provider），
再流式取回结果。所以「设置里配好什么模型，插件就用什么模型」。

- **块级 AI 写作助手**：块菜单 →「AI 写作助手」，可选 **改写 / 续写 / 润色 / 翻译**，
  结果**流式**出现在面板里（`POST /api/ai/stream`），生成中只读、结束后可直接编辑，
  然后「替换块」或「插入到下方」，也能复制。
- **页面级 AI 摘要与标签**：`⋯` 菜单 →「AI 摘要与标签」，对整页正文生成 3-5 条要点或 3-5 个标签
  （同样流式），可插入到页面开头或复制。
- **Agent 整理（多步工具循环）**：`⋯` →「AI 摘要与标签」→ 选「Agent 整理」，用一句话下达任务
  （例如"把这篇笔记整理成小节并补 3 条摘要"）。插件会用 DSH 的模型跑一个小型工具循环：
  模型输出 JSON 动作（list / read / search / write），Host 执行并回传结果（最多 6 步），
  完成后自动写回笔记并刷新面板。实测能把一篇散记整理成「摘要 + 小节」结构。
- **当前笔记注入 Agent 上下文**：打开任意笔记时面板会把路径上报给 Host，Host 通过
  `systemPrompt.context` 注入「用户正在编辑 xxx」的上下文——对话里的 Agent 因此知道你正在看哪篇。
- **`/note` 命令**：
  - `/note` 显示当前笔记；`/note 名字` 切换当前笔记（唯一匹配时），Agent 上下文随之切换；
  - `/note save [标题]` 把当前会话最近 20 条对话**保存成一篇笔记**（frontmatter 记录来源与 session id）；
  - `/note new [标题]` 在笔记库根目录新建一篇空笔记。
- **写前快照**：任何写入（含 AI Agent 改写）前都会在 `.dsh-notebook-history/` 留一份旧内容快照；
  Agent 结果面板会提示这一点，并提供「查看版本历史」直接回滚。
- **上下文增强**：注入给模型的不只是路径，还有笔记标题与最多 12 条大纲；`/api/current` 也返回这些信息。
- **聚焦块上下文**：在面板里编辑某一段时，客户端会把「所在标题 + 块类型 + 当前文字（最多 500 字）」
  上报给 Host（`POST /api/focus`，停止输入约 0.7 秒后同步），下一轮提示里就会出现
  「用户当前聚焦在「小节」下的段落：…」，所以对话里说「把这段改一下 / 润色这里」时模型不用猜；
  切换笔记自动清空，`/note` 也会显示当前聚焦。
- **双向实时同步**：面板打开笔记时每 3 秒探测一次文件 mtime（`GET /api/stat`，不读正文）。
  Agent 工具或 Obsidian 改了这篇笔记时：页面干净时**自动重新载入**；正在编辑时顶部出现
  「这篇笔记在别处被修改了」提示条，可一键重新加载或忽略；有未保存修改时不动它，
  保存仍走 `expectedMtimeMs` 冲突保护；真的撞上冲突时也不只弹一句错误，而是给
  同样的「重新加载 / 忽略」横幅，避免误覆盖。
- **`/note ask <问题>`**：在对话里直接问当前笔记——走问答右栏同款只读 Agent
  （可读/搜整个库，不能写），答案作为命令结果回到对话；例如 `/note ask 这篇笔记的结论是什么`。
- **`/note agent <任务>`**：用 Harness 原生 fork provider 启动一个**子 Agent**（继承父会话工具，含 notebook
  工具），它完成后把结果作为消息投回当前对话——这是"AI 结果进会话"的原生实现。
- **`@笔记名` 引用**：在 AI 面板的指令里写 `@会议纪要`，Host 会把该笔记内容（最多 2000 字）附加到提示，
  单次 AI 与 Agent 模式都支持。
- **问 AI 右栏**：顶栏 ✨ 打开笔记本自己的右侧问答栏。
  - 「问这篇笔记」：把当前笔记全文（最多 1.6 万字）和聚焦段落交给模型，回答用
    SSE 流式显示（`POST /api/ask`），可随时「停止」；
  - 「Agent 查库」：只读工具循环（`POST /api/ask/agent`，SSE 推送；list / read / search，
    写操作在 Host 端直接拒绝），能跨笔记检索后再回答，面板会随着每次检索实时涨步数；
  - **选中文字提问**：在笔记里选中一段文字再点 ✨——也可以直接用编辑时浮出的格式工具栏
    最右边的 ✨；问题会
    带上这段选中文字，模型知道「这段 / 这里」指什么；选中内容显示在右栏上下文里，可一键清除；
  - 回答按 Markdown 只读渲染（标题 / 列表 / 待办 / 代码 / 引用 / 表格 / 行内格式，
    原始 HTML 会被转义、链接只放行 http(s)/mailto）；
  - **引用可点**：回答里的 `[[笔记名]]` 和库内 `.md` 路径会变成链接，点一下直接打开
    那篇笔记（找不到会提示）；提示词也要求模型这样引用；
  - 空白对话给出快捷提问（总结要点 / 待办与下一步 / 解释选中文字）；
  - 每条回答可「复制」「插入到笔记」或「存为笔记」——插入落在**正在编辑的那个块后面**
    （没在编辑时追加到末尾），作为真实块保存且可撤销；存为笔记用回答第一行做标题、
    落在当前目录、重名自动加序号并打开；Agent 模式会显示检索步数；
  - 右栏标题显示本次回答使用的 provider/model（`/api/ask` 先推一条 meta 事件）；
  - 请求失败时错误条旁有「重试」，原地重跑最后一个问题（不会多一条提问）；
    标题旁的 ⟲ 清空当前笔记的对话；每篇笔记各自保留对话，切回来还在；
    Enter 发送、Shift+Enter 换行，Esc 关闭右栏；`Ctrl/Cmd + Alt + J` 开合问答栏
    （注册进 DSH 的快捷键服务，会出现在快捷键设置与参考里）。
  （DSH 原生右侧栏只在会话界面可用，笔记面板是全局面板，所以问答栏做成笔记本自己的右栏。）
- **对话里的笔记卡片**：Agent 调用 `notebook_read` / `notebook_write` / `notebook_list` /
  `notebook_search` 时，会话里显示一行笔记卡片（动作 + 笔记名 + 覆盖/追加/新建、大小或命中数），
  展开可预览笔记内容、写入内容或搜索结果；点「打开」直接切到笔记本并打开那篇笔记
  （笔记本已打开时立即切换，未打开时等它挂载后跳转）；写入卡片还多一个「历史」，
  打开该笔记并直接弹出它的版本历史，方便回滚 Agent 的改写。搜索卡片的结果逐条可点，
  直接打开命中所在的那篇笔记。
- 输入上限 8000 字符、单次 60 秒超时、任务白名单校验；未配置模型或调用失败会以错误提示返回。

## 集合视图（L3：文件级数据库）

- 新建笔记时选「数据库页」模板（或手动在 frontmatter 写 `type: collection`），这一页会把
  **同目录（或 `source` 指定目录）下所有笔记的 frontmatter 字段**聚合成视图：
  - **表格视图**：列自动取出现最多的字段（也可用 `columns: 字段1, 字段2` 指定），点列头排序，
    顶部搜索框按名称/路径/字段值筛选，点行打开对应笔记；
  - **看板视图**：按 `groupBy` 字段（默认 `status`）分组，卡片显示名称 + 前两个字段，点卡片打开笔记。
- **可编辑**：点表格单元格直接改字段值（回车保存、Esc 取消，写回该笔记 frontmatter）；
  **看板拖拽**卡片到另一列即改写 `groupBy` 字段；工具栏「+ 新建条目」在数据源目录创建一篇新笔记。
- **保存视图**：工具栏「保存视图」把当前 `view` / `filter` / `sort` / `groupBy` 写回页面 frontmatter，
  下次打开自动恢复；「条件过滤」支持 `status = done and points > 2`、`tags ~ infra` 这类条件
  （`= != > < >= <= ~`，`~` 为包含，`and` 连接，数值自动按数字比较），与顶部搜索框叠加生效。
- 数据由 Host 的 `GET /api/fields?folder=` 提供（只读每篇前 2KB 的 frontmatter，跳过复杂 YAML）。

## 目录页（文件夹索引）

- 正文**只有指向同目录笔记的链接**的页面（例如 `笔记/01 工作/工作.md` 里逐条写着
  `[Linux](<./Linux.md>)`…，至少 3 条），打开时自动识别为**目录页**：链接列表被**实时目录**替代，
  行尾显示大小与修改日期，点一下直接打开那篇笔记；顶部可按名称/最近修改排序、按名称筛选。
- 子文件夹单独成行（显示其中的笔记数），点一下就地展开/收起，展开后列出该文件夹的直接笔记；
  列表末尾的「+ 新建笔记」直接走模板选择，新笔记落在该目录里。
- 原文一个字节都不改：底部「查看原文」随时切回原来的链接列表；改回普通正文（加一句说明）后
  自动检测即失效，页面恢复成普通笔记。
- 想固定目录页形态（或正文不是纯链接，例如放在 `笔记/00 首页/` 的总目录页），用 `⋯` →
  「设为目录页」在 frontmatter 写入 `type: folder`，再点一次取消；`folder: 笔记` 可以让这一页
  展示**别的目录**。目录页永远读当前笔记列表，新建、重命名、移动后立即反映，不用手工维护链接。

## 写作热力（GitHub 风格小绿块）

- **侧栏底部**常驻一个 18 周的小热力图，标题旁显示累计字数；点开是全年 53 周的大图
  （命令面板里也能打开「写作热力」）。格子用 5 档绿色，悬停显示「日期 · 字数」。
- **统计口径**：每次通过面板 / Agent 保存，按「这次实际插入的字符数」累计（普通编辑取
  新旧文本公共前后缀之间的新增段，替换文字也算写作；整篇重写/重排时退回净增长，避免把
  挪动段落算成几千字），只累计正增量，按本机时区的自然日归档；单日最大值决定 5 档的深浅。
- **存储**：`<笔记库>/.dsh-notebook/writing.json`（隐藏目录，Obsidian 不索引），
  由 Host 的 `GET /api/stats/writing` 读出；大图里的「总计 / 活跃天数 / 连续天数 / 最高单日」
  都在 Host 侧算好。
- **历史从启用日开始**：文件的 mtime 无法还原写作历史（这个库所有笔记的 mtime 都是同一天，
  说明是从别处拷贝来的），所以不在启用前虚构数据；首次启用只用「今天保存过的笔记正文长度」
  给今天做一次种子，之后逐日累计。

## 双向链接

- `[[笔记名]]` 渲染为可点击链接（支持 `[[笔记名#标题]]` 跳到指定标题），`![[笔记名]]` 渲染为只读嵌入。
- 普通 Markdown 链接 `[文字](相对路径.md)` 也会在面板里解析成笔记链接：支持 `../`、中文/空格、
  `[文字](<带 空格 的路径.md>)` 这种尖括号写法以及 `#锚点`；指向不存在笔记时保持原样，外链仍是外链。
- 每页正文底部有**「链接」区**，**默认折叠**成一行（显示反向链接 / 出链 / 提及的数量），
  点一下展开，展开状态会记住：
  - **反向链接**：哪些笔记链接到了本页（由 Host 扫描整个笔记库，带来源行号，悬停可看原行）；
  - **出链**：本页引用了哪些笔记/嵌入（从块文本提取，自动去重）；
  - 点任一条直接跳转，出链也支持打开不存在的笔记名（会提示找不到）。
- 斜杠菜单 →「双链笔记」：搜索笔记名并选择，自动在当前块插入 `[[笔记名]]`。
- **输入即补全**：在任意块里敲 `[[` 会弹出笔记候选浮层（继续输入按名字过滤），`Enter` / `Tab`
  选第一项、`Esc` 关闭、也可直接点击；选中后自动补成 `[[笔记名]]` 并把光标放到链接后面。
- **未链接提及**：正文里提到某篇笔记的名字但没加链接时，页底「提及」区会列出来（带出现次数），
  点「加链接」把纯文本替换成 `[[笔记名]]`（已有链接和代码块不动）。
- **关系图谱**：`⋯` →「关系图谱」弹出 SVG 图：中心是当前笔记，右侧是它的出链、左侧是反向链接，
  连线表示关系，点任意节点直接打开那篇笔记。

## 视觉

- 所有颜色取自宿主主题 token（`--dsw-alias-*`），浅色 / 深色主题自动适配；强调色用宿主的
  `--dsw-alias-link`（蓝色），hover / 选中用半透明叠层，避免与底色同色而"看不见"。
- 统一圆角（6 / 8 / 12px）与两级阴影（`--nb-shadow-1/2`）；输入框聚焦有柔和光环。
- **动效系统**：两套缓动——hover / 状态切换用 `--nb-ease`（120–140ms），所有进场用
  `--nb-ease-out`（expo-out，160–200ms）。菜单、笔记菜单、wiki 补全、图标面板从
  `top left` 缩放，代码语言菜单从 `top right`，模态卡片中心缩放；命令面板 180ms、
  问 AI 右栏 200ms 横向 8px 入场、模态/菜单 160–180ms、遮罩 120ms 淡入。保存中的状态点
  有 1.2s 呼吸，保存完成即停；失败 / 冲突提示条 180ms 下滑淡入。
- **微交互**：切换标注类型时底色 280ms 交叉淡入；标注图标 hover 轻抬、按下回弹；
  勾选待办时 √ 弹入；问答里最新一条消息 220ms 上浮；集合卡片 hover 抬起 1px 并加阴影；
  按钮按下缩到 0.96、图标按钮缩到 0.92。
- **可访问性**：`prefers-reduced-motion: reduce` 下关闭全部动画与过渡（含滚动跳转，
  JS 里也会检测并回退为瞬时滚动）。
- 侧栏按目录层级缩进，选中项用中性的 `--nb-active` 底色 + 600 字重（不再用色条）；分组标题、
  计数、保存状态等元信息统一到 11px 半粗；搜索框在侧栏里是无边框的浅填充，聚焦才出现描边。
- 正文行高 1.68，标题 1.9 / 1.45 / 1.2em 三级递减，页面标题 2.4em——页面标题与正文 H1 拉开层级；
  块 hover 有可见底色；空状态重新排版（大标题 + 留白 + 主按钮）。
- 顶栏「已保存」带状态圆点（保存中 / 未保存为琥珀色、失败为红色）；命令面板底部有 ↑↓ / ↵ / esc
  键盘提示；集合视图工具栏拆成「主区（视图 + 搜索 + 计数）+ 操作区（条件过滤 / 保存视图 / 新建 / 刷新）」，
  窄宽度下也不再挤成三行。
- 交互细节：自定义选区色、`caret-color` 跟随强调色、细滚动条、搜索命中高亮；问 AI 右栏有 180ms
  的横向入场，并在 `prefers-reduced-motion: reduce` 下关闭所有动画/过渡。
- 自绘细滚动条、统一选区色、搜索命中柔和高亮。
- **字体**：`⋯` →「字体」面板可选 8 种预设（默认 / Inter / 思源黑体 / 微软雅黑 / 衬线宋体 /
  楷体 / 霞鹜文楷 / 等宽），每项用自身字体渲染预览，面板里也能调字号；还能输入任意
  CSS `font-family` 自定义栈（自动过滤不安全字符）。字体**只作用于正文**，侧栏和菜单保持系统 UI 字体；
  选择会记住。
- **排版向 Notion 靠拢**：正文页宽 720px、行高 1.68；页面标题 38px、正文标题 30 / 23 / 19px 三级阶梯；
  块圆角 4px、待办方框 4px、封面 200px 高。

## 配置

没有可用笔记库时，面板不再只弹一条错误提示，而是显示一张引导页：去哪个设置项选目录、
留空如何自动检测，并把 Host 的原始原因列在下面。

最方便的是 **设置 → 通用 → 笔记本笔记库**：显示当前笔记库路径（自动检测的会标注），
「选择目录…」调用 Harness 的原生目录选择器，选完通过 `ctx.configEditor` 写回插件行配置并重启
插件（面板会自动清空并重新载入新库）；「自动检测」把 `vaultPath` 清空。
其余字段仍在 `cordis.patch.yml`（或插件管理页的配置入口）里：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `vaultPath` | `''` | 笔记库的绝对路径。留空时自动读取 Obsidian 的最近仓库列表（macOS `~/Library/Application Support/obsidian`、Windows `%APPDATA%/obsidian`、Linux `~/.config/obsidian`），优先用当前打开的那个，否则用最近打开的。 |
| `maxNoteBytes` | 2097152 | 单篇笔记上限，超过时编辑器和 Agent 工具都会拒绝。 |
| `maxIndexFiles` | 5000 | 列出/搜索时最多枚举的 Markdown 文件数，超出会截断并标记。 |
| `templateDir` | `模板` | 新建笔记时把哪个目录里的笔记列为自定义模板。 |
| `attachmentDir` | `附件` | 粘贴图片保存到笔记库里的哪个目录。 |
| `maxAttachmentBytes` | 8388608 | 单张图片上限，超过会被拒绝。 |
| `flashDir` | `闪念` | 闪念笔记单独存放的目录（库内相对路径）。每条闪念是一个 `.md`，Obsidian、搜索和同步都照常看得见。 |

## 闪念

一个独立文件夹收集零散的记忆片段，设计参照 [flash-capsule](https://github.com/whd-1999/flash-capsule) 的三条原则：
**捕获零决策、入口无处不在、捕获与处理分离**。

- **闪念标签页**：从侧栏「⚡ 闪念」或命令面板打开，标签栏里会多一个可切换、可关闭的「⚡ 闪念」标签，和笔记标签并列；
  关掉后可从侧栏重新打开，刷新页面会记住这个标签。
- **记一笔**：侧栏 ⚡、顶栏 ⚡、快捷键 `⌘⇧F`（`Ctrl+Shift+F`）、命令面板里的「记一笔」、或让 Agent 调 `notebook_flash`。
  一个输入框，回车就存，不用选文件夹也不用起标题；分类可以点，也可以完全不管（默认「随记」）。
- **对话里直接记**：在 DSH 对话框输入 `/flash <想法>` 就存一条，`/flash <分类> <想法>` 可指定分类
  （随记/想法/待办/灵感/摘录），`/flash` 单独发则列出收件箱；`/闪念` 是同一功能的别名（Host 接受中文命令名时可用）。
- **聊天里的想法会被接住**：插件会告诉模型「什么时候该记」——当你说「记一下 / 帮我记 / 别忘了我刚说的」，
  或抛出一个以后想继续发展的想法、待办、灵感时，它会直接调 `notebook_flash` 存进闪念，
  再回一句「已记下」；普通问答、代码、命令输出和寒暄不会建闪念，每次回复最多记一条。
- **自动落盘**：每条闪念是 `闪念/2026-11-10 14-40-12 想法的第一行.md`，frontmatter 记录
  `type: flash`、`created`、`category`、`tags`、`pinned`、`done`。所以它在 Obsidian 里就是普通笔记，
  能被全文检索、双链、目录页和 WebDAV/git 同步覆盖。
- **之后再整理**：闪念面板按「未处理 / 全部 / 已完成」筛选，按分类和关键词过滤；
  卡片上可以置顶、标记完成、打开笔记、**就地编辑正文和分类**、删除（进 `.trash/`，不是永久删除）。
- **翻旧账**：随机翻出一条旧闪念，优先未完成、未置顶、已经放了一天以上的，直接打开。

捕获路径只做一次本地写入，不联网、不调用模型；整理和分类全部留到以后。

## 对话与笔记

- **当前笔记自动进上下文**：打开哪篇笔记、大纲、光标所在块（约 300 字）每轮自动带给模型，所以「这段 / 这里」指代明确。
- **工具按需取材**：`notebook_list` / `notebook_read` / `notebook_search` / `notebook_write`，可以「先看看我上周写的 XX 再回答」。
- **输入框引用笔记**：对话框左侧笔记本按钮 →「引用笔记…」，搜索并勾选多篇，插入内容只有路径：
  `@[[路径1]] @[[路径2]]`，一行搞定。Host 会告诉模型 `@[[路径]]` 表示引用了一篇笔记，
  需要内容时自己用 `notebook_read` 读取——不占输入框、也不预先消耗上下文。
- **语义检索**：`notebook_search` 传 `semantic: true` 时按意思排，而不是只找字面。做法是
  「模型把查询扩展成同义/相关词 + 本地中文 bigram 与词命中加权排序」，返回相关笔记和摘要片段；
  没有 embedding 服务可用，所以这不是向量检索，但「系统升级坏了」这类说法能命中写着「升级 / 回滚」的笔记。
  对应路由 `GET /api/recall?q=&expand=0`（`expand=0` 关掉模型扩展，只做本地排序）。

## 同步（WebDAV / Git 仓库）

面板右上角的 **⟳** 打开同步弹窗，选「关闭 / WebDAV / Git 仓库」。按钮上的小圆点就是状态：
绿=上次成功、灰=未启用、橙=正在同步、红=上次失败。

### WebDAV

填服务器地址（要带路径，例如 `https://dav.example.com/remote.php/dav/files/我`）、用户名、密码，
可再填一个远程子目录。「测试连接」会真的建目录、写一个探针文件再删掉，所以 401（账号密码）
和 403（只读账号 / 目录不允许 PUT）在保存前就能看出来；失败原因同时显示插件给出的中文说明和服务器原文。

### Git 仓库

填远程仓库（SSH 或 HTTPS，可留空——那样只在本机提交版本）、分支、提交信息。SSH 远端凭据沿用本机的
git 配置（ssh key、credential helper）；HTTP(S) 远端（如自建 Gitea）在后台同步时无法弹窗，需要在同步设置里填
**用户名 + 密码/访问令牌**，插件用环境变量把它们交给一个临时 credential helper（令牌不会出现在进程参数里）。
凭据保存在库内 `.dsh-notebook/sync.json`（0600，不参与同步、不进 git）。一次同步依次做：
`git add -A` → 有改动就 `commit` → `fetch` → 落后就 `rebase origin/<分支>` → `push`；
base 冲突会中止 rebase 并把冲突文件列出来，仓库不会卡在 rebase 中间。
远程不可达时不会挂死：SSH 默认走 `BatchMode=yes`（不弹密码/口令提示，也意味着无密码密钥或 ssh-agent
是前提）、15 秒连接超时；fetch/push/ls-remote 最多 60 秒，超时会连同它启动的 ssh 子进程一起杀掉并报
「git 命令超时」。HTTP 远端另外限制低速传输（低于 1 KB/s 持续 20 秒即中断）。

### 行为

- **双向**：本地改动上传、远端改动下载；两边都改过的笔记保留本地版本，远端内容另存为
  `笔记名 (冲突 2026-11-10 14-30-00).md`，并在这次同步里一起上传。
- **首次同步**不会删除任何东西。两边同一个路径都有文件时，比较内容后保留较新的一份，
  另一份放进 `.trash/first-sync-<时间>/`。
- **删除**默认同步，但都可恢复：远端删掉的本地副本、本地删掉的远端副本都会先备份到 `.trash/`；
  也可以把「删除处理」改成「不传播删除」。
- **保护**：一次要删掉超过 200 个文件、或超过已跟踪文件的 25% 时整次同步直接停止（一个文件都不删），
  避免远端填错目录把笔记库清空；单文件超过 64 MB 跳过并报错。
- 可选项：保存笔记后自动同步（防抖 4 秒）、每 N 分钟定时同步。面板与 Agent 写笔记走同一条
  `vault.write`，所以两种自动同步都覆盖到。

### 状态与配置放在哪

`<笔记库>/.dsh-notebook/`：`sync.json`（设置，权限 0600，WebDAV 密码也在这里）、
`sync-state.json`（上次双方一致的内容哈希与 ETag，用于三方比较）。这个目录不参与同步，
git 下会自动写进 `.git/info/exclude`，因此不会被提交或推送。删掉 `sync-state.json`
等于让下一次同步按「首次同步」处理。

- **历史与重试**：同步弹窗可展开最近 10 次运行的记录（时间、触发方式、计数、错误）；WebDAV 的读请求
  （GET / PROPFIND / MKCOL / DELETE）遇到瞬时 5xx 或断连会重试 2 次（300ms、1.2s 退避）。
- **SSH 开关**：默认 `BatchMode=yes` 快速失败；口令/Keychain 场景可勾选「沿用系统 ssh 配置」。

HTTP 路由：`GET /api/sync/status`、`POST /api/sync/settings`、`POST /api/sync/test`、`POST /api/sync/run`。
Agent 也能用 `notebook_sync` 查看状态、测试连接、触发一次同步。

## Agent 工具

- `notebook_list` — 列目录：直接子笔记 + 每个子文件夹的笔记数（`recursive: true` 列整棵子树，
  `limit` 默认 100）——大笔记库里不再一次倒出几百行
- `notebook_read` — 按笔记库相对路径读取整篇笔记
- `notebook_search` — 全文检索，返回 `路径:行号: 内容`；`semantic: true` 时按语义相关度返回笔记与摘要片段
- `notebook_write` — 写入笔记，`mode` 为 `replace`（默认）/ `append` / `create`
- `notebook_sync` — 同步状态 / 测试连接 / 立即同步一次（`action` 为 `status` / `test` / `run`）
- `notebook_flash` — 记一条闪念 / 列出未处理 / 随机翻一条（`action` 为 `capture` / `recent` / `random`）

## 安全边界

- 所有路径在 Host 端归一化，`..`、绝对路径、非 `.md` 文件、`.obsidian` / `.trash` / `.git` 等内部目录一律拒绝；
  写入与读取都做 realpath 校验，符号链接不能把访问带出笔记库。
- HTTP 路由只接受同源请求（校验 `Host` 与 `Origin`，防 DNS rebinding）。
- 写入使用临时文件 + rename 的原子替换；带 `expectedMtimeMs` 保存时，若磁盘上的副本已被外部修改会报冲突而不是覆盖。
- 删除是把笔记移入笔记库的 `.trash/`，不是永久删除；版本快照保留最近 20 个。

## 文件

- `index.js` — Host 半：笔记库服务、`/notebook/api/*` 路由（含附件、历史、闪念与同步）、六个 Agent 工具、Config。
- `flash.js` — Host 半的闪念服务：单个文件夹、frontmatter 往返、置顶/完成/随机翻旧账。
- `sync.js` — Host 半的同步引擎：WebDAV 客户端（PROPFIND/MKCOL/PUT/GET/DELETE + 三方清单）与 git 提供方。
- `client.js` — Client 半：`sidebar.panellist` 入口 + `main` 块的 Notion 式页面。
- `cordis.patch.yml` — 插入 Host 行的 bundle patch。
- `locale/{zh,en}.json` — 插件管理页的标题与描述。
