# dsh-notebook

把 DeepSeek Harness Web UI 当作一个 Notion 式的笔记本：打开就是渲染好的页面，点哪里就能改哪里，
没有「编辑 / 预览」模式切换。笔记来自一个 Obsidian 仓库目录（只当作磁盘上的 Markdown 文件夹），
但在 DSH 内渲染和编辑，不打开、不嵌入 Obsidian；对话中的 Agent 也能读写同一批笔记。

## 编辑方式

### 文本与格式

- 打开笔记即是渲染后的页面：标题、段落、列表、待办、引用、代码、分隔线都按样式显示。
- **点击任意块**即可在原位编辑；编辑时块内格式（**加粗**、*斜体*、`行内代码`、~~删除线~~、链接）
  直接以样式显示，不再看到 Markdown 标记；输入 `**文字**`、`*文字*`、`` `文字` ``、`~~文字~~`
  时**闭合标记一敲下就变样式**。失焦后回到渲染态并自动保存（停止输入约 1 秒）。
- `Ctrl/Cmd+B` 加粗、`Ctrl/Cmd+I` 斜体；选中文字浮出格式工具栏（加粗 / 斜体 / 删除线 /
  行内代码 / 链接 / 清除格式），点按钮不会丢失选区。
- `Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 或 `Ctrl+Y` 重做（连续输入合并成一步）。
- `Ctrl/Cmd + =` / `Ctrl/Cmd + -` 快速增减正文字号。
- `Ctrl/Cmd+F` 页面内查找：输入关键词实时显示命中块数，`Enter` / `Shift+Enter` 上下跳转，
  跳转目标块会短暂高亮；`Esc` 关闭。
- 点击正文里的链接弹出编辑条：改地址、打开、移除链接（保留文字）。
- `[[笔记名]]` 会渲染成可点击链接，点击直接打开对应笔记（按名称或路径匹配，找不到会在顶部提示）；
  `[[笔记名#标题]]` 会打开笔记并滚动到该标题；反向链接与出链见下方「双向链接」一节。
- `![[笔记名]]` 形式的**嵌入引用**会在当前块内渲染那篇笔记的只读内容（标题、列表、引用、代码等），
  超过 12 块折叠成「展开全部」、展开后可再「收起」；点嵌入区标题可直接打开原笔记；嵌套深度最多两层。

### 块与结构

- **页面模板按钮**：斜杠菜单 →「模板按钮」插入一个虚线按钮（存为 `[新建页面](nb://template)`），
  点击后选模板即可当场以该模板**创建子页面**（自动写入 `parent`，进入侧栏树）。
- **Emoji 短代码**：输入 `:smile:`、`:rocket:`、`:tada:` 等 50+ 个短代码，闭合冒号时立即变成对应 emoji
  （纯文本块内生效，不影响行内格式）。
- 输入 Markdown 语法即时变块类型：`# ` `## ` `### ` 标题、`- ` 列表、`1. ` 编号、`- [ ]` 待办、
  `> ` 引用、``` 代码、`---` 分隔线。
- 输入 `/` 打开插入菜单，继续输入按名称或别名过滤（`/h2`、`/todo`、`/代码`、`/list`…），
  `Enter` 选第一项、`Esc` 关闭。
- `Enter` 拆分块；空标题 / 空列表按 `Enter` 回到正文；`Shift+Enter` 块内换行；
  空块 `Backspace` 先回到正文（正文空块再退格合并到上一块），`Esc` 退出编辑。
- 悬停块左侧出现 `+`（在其后插入一块）和 `⋮⋮`：按住 `⋮⋮` 拖动调整顺序（带幽灵预览、边缘自动滚动），
  单击打开块菜单；悬停块**右侧**出现 `⋯`，同样打开块菜单（改类型、上移 / 下移、**转为子页面**、
  **复制块链接**、删除）；触摸屏长按块也能打开菜单。双击块直接进入编辑。
- **块级锚点引用**：「复制块链接」会给块生成稳定 id（写回 Markdown 行尾 ` ^id`）并复制
  `[[笔记#^id]]`，粘贴到别处点击即可跳转到那一段；已有 id 的块直接复用。
- 「转为子页面」把该块的内容变成同目录下的一篇新笔记，原位置留下 `[[标题]]` 链接（Notion 的页面嵌套）。
- 列表 / 待办 / 段落 / 引用支持**缩进层级**：块内按 `Tab` 加深、`Shift+Tab` 减浅（最多 3 级），
  序列化为两个空格一层，可与其他 Markdown 编辑器互认；代码块内 `Tab` 插入两个空格。
- 标题左侧 `▾ / ▸` 折叠该标题下内容，直到下一个同级或更高级标题。
- `/callout` 或 `> [!note] 内容` 得到**提示块**（note / tip / warning / danger / success… 自动配图标）。
- `/toggle` 或 `> [!toggle] 标题` 得到**折叠列表**：下面缩进的块是内容，点箭头收起/展开，
  收起状态写回 `> [!toggle]-`，重开笔记仍保持。
- **代码块**：悬停右上角语言标签切换语言（`js`、`python`…），保存为 ```lang 围栏；失焦后按注释 /
  字符串 / 数字 / 关键字着色。
- **表格**：`/table` 插入或粘贴 Markdown 表格自动识别（保留 `:---:` / `---:` / `:---:` 对齐）；
  单元格点选即编辑，`Tab` / `Shift+Tab` 跳格、`Enter` 下移、`Shift+Enter` 单元格内换行
  （存成 `<br>`，Obsidian 里也能正常显示）；悬停出现 `+ 行 / + 列 / - 行 / - 列`；
  行左侧 `⋮⋮` 拖动调整行顺序、表头左侧 `⋮⋮` 拖动调整列顺序（对齐一起移动）；
  表头右边界拖拽条调整列宽（按笔记记住，不写进 Markdown）。
- **图片**：粘贴截图、把图片拖进编辑块或拖到页面任意位置，存进笔记库 `附件/`（`attachmentDir` 可配），
  写入 `![](附件/xxx.png)` 并直接显示；斜杠菜单「图片」可输入 URL 插入；点击图片弹出控制条改 alt、
  按 `25% / 50% / 75% / 100%` 设宽度（写回 `{width=50%}`）、移除图片。
- 粘贴多行 Markdown 会按块解析并插入，而不是挤进一行。

### 多选与移动

- **Shift+点击**另一个块可多选（选区变灰），`Backspace` / `Delete` 批量删除，
  `Ctrl/Cmd+C` 复制、`Ctrl/Cmd+X` 剪切，`Esc` 取消；按住任一选中块的 `⋮⋮` 拖动可**整组移动**。

### 组织与导航

- **面包屑**：正文顶部显示 `笔记库 / 目录 / 当前页`，点目录直接展开侧栏对应分组（禅模式自动隐藏）。
- **子页面树**：用块菜单「转为子页面」创建的子笔记会在 frontmatter 写入 `parent`，侧栏里按父子关系
  嵌套缩进显示（父页 → 子页 → 孙页），不再是平铺列表。

- **编辑时右侧悬浮大纲**：进入任意块的编辑状态后，右上角浮出当前笔记的大纲（标题层级缩进、
  当前章节高亮），点一下即可跳转；退出编辑自动隐藏，窄屏不显示。
- **收藏与最近打开**：右键笔记可「收藏」，侧栏顶部列出收藏（★）和最近打开的 5 篇（⟲），点一下即跳转。
- **快速打开（Ctrl/Cmd + P）**：弹出居中的搜索面板，按名字/路径过滤笔记，`↑` / `↓` 选择、
  `Enter` 打开、`Esc` 关闭——不离开当前页面就能切到任意笔记。
- 左侧栏：搜索（命中词高亮）、新建笔记/新建文件夹、按目录分组的笔记列表（目录可折叠；右键笔记可
  收藏、重命名、**移动到…**、复制路径、删除；**把笔记拖到目录标题上即可移动**）；当前目录跟随打开的笔记展开。
  侧栏不再显示大纲（避免与笔记列表挤在一起），大纲只在编辑时以右侧悬浮卡片出现。
- 打开的笔记在顶部形成**标签页**，点击切换、`×` 关闭；刷新后标签组会恢复。
- 触摸屏上左右滑动正文可切换相邻标签页。
- 每篇笔记会**记住自己的滚动位置**，切回来接着看。
- 打开插件时自动恢复上次编辑的笔记。

### 页面设置

- 页面标题可直接点击修改（等于重命名文件）。
- 标题上方可加 **emoji 图标**与**封面**（图片 URL 或笔记库相对路径），分别存在 frontmatter 的
  `icon` / `cover` 字段，Obsidian 也能看到；原有 frontmatter 其他字段保持不变。
- **禅模式（Zen）**：`Ctrl/Cmd + Shift + F` 或顶栏 `◨` / `⋯` 菜单进入。侧栏、顶栏、图标与封面、
  块把手、添加按钮、页底链接区全部隐藏，连宿主 DSH 的侧栏也会自动收起，只留正文和光标；
  右上角半透明的「退出禅模式」按钮或 `Esc` 退出（退出后恢复此前收起的侧栏）。
- `⇤ / ⇥` 切换默认 / 全宽排版。
- `⋯` 菜单：更换图标、加/移除封面、导出、版本历史、快捷键、字号、阅读模式、删除笔记。
  **阅读模式**隐藏块把手、添加提示和悬停底色，只留正文（状态记住）。
- 左侧「新建笔记」先选**模板**：内置空白 / 会议记录 / 今日记录 / 项目计划 / 读书笔记，
  另外会把笔记库 `模板/` 目录（可用 `templateDir` 配置）里的笔记列为**自定义模板**
  （选中即用其内容建新笔记）；
  新建后自动聚焦标题并全选，直接输入即可改名。

### 导出与历史

- `⋯` 菜单可**导出**当前笔记为 Markdown、独立 HTML 或直接**打印 / 存为 PDF**（打印样式只输出正文，
  隐藏侧栏、块把手等界面元素）。
- `⋯` →「版本历史」查看每次保存留下的快照（保留最近 20 个），预览显示**与当前内容的行级差异**
  （红色 = 恢复后消失，绿色 = 恢复后加回；只展开改动附近 3 行，其余折叠成「… N 行未改动」），
  可一键恢复；快照存在笔记库 `.dsh-notebook-history/`（隐藏目录，Obsidian 与列表都看不到）。
- `⋯` →「页面属性」编辑 frontmatter 的 **tags / aliases**：标签以 chip 形式展示，回车添加、点 × 删除、
  退格删最后一个（写入 `tags: [...]`）；aliases 逗号分隔；下方列出其余字段（可逐行编辑，
  清空即删除该字段），也可**新增字段**（字段名限字母/数字/下划线/短横线）；YAML 多行 / 嵌套值
  以只读形式展示（避免误改破坏结构）；面板顶部可换图标、
  加/移除封面；其他 frontmatter 字段保存时原样保留。
- `⋯` →「快捷键」查看全部快捷键。

## AI 能力（用 DSH 自己的模型）

插件不自带 API key、不新增 provider 配置——所有 AI 调用都走 Harness 自己的模型服务：
Host 通过 `ctx.llm` 与 `agentDefaultModel` 解析当前默认模型（没有默认时回退到第一个可用 provider），
再流式取回结果。所以「设置里配好什么模型，插件就用什么模型」。

- **块级 AI 写作助手**：块菜单 →「AI 写作助手」，可选 **改写 / 续写 / 润色 / 翻译**，
  结果出现在面板里可直接编辑，然后「替换块」或「插入到下方」，也能复制。
- **页面级 AI 摘要与标签**：`⋯` 菜单 →「AI 摘要与标签」，对整页正文生成 3-5 条要点或 3-5 个标签，
  可插入到页面开头或复制。
- **Agent 整理（多步工具循环）**：`⋯` →「AI 摘要与标签」→ 选「Agent 整理」，用一句话下达任务
  （例如"把这篇笔记整理成小节并补 3 条摘要"）。插件会用 DSH 的模型跑一个小型工具循环：
  模型输出 JSON 动作（list / read / search / write），Host 执行并回传结果（最多 6 步），
  完成后自动写回笔记并刷新面板。实测能把一篇散记整理成「摘要 + 小节」结构。
- **当前笔记注入 Agent 上下文**：打开任意笔记时面板会把路径上报给 Host，Host 通过
  `systemPrompt.context` 注入「用户正在编辑 xxx」的上下文——对话里的 Agent 因此知道你正在看哪篇。
- **`/note` 命令**：
  - `/note` 显示当前笔记；`/note 名字` 切换当前笔记（唯一匹配时），Agent 上下文随之切换；
  - `/note save [标题]` 把当前会话最近 20 条对话**保存成一篇笔记**（frontmatter 记录来源与 session id）；
  - `/note new [标题]` 在笔记库根目录新建一篇空笔记。
- **写前快照**：任何写入（含 AI Agent 改写）前都会在 `.dsh-notebook-history/` 留一份旧内容快照；
  Agent 结果面板会提示这一点，并提供「查看版本历史」直接回滚。
- **上下文增强**：注入给模型的不只是路径，还有笔记标题与最多 12 条大纲；`/api/current` 也返回这些信息。
- 输入上限 8000 字符、单次 60 秒超时、任务白名单校验；未配置模型或调用失败会以错误提示返回。

## 集合视图（L3：文件级数据库）

- 新建笔记时选「数据库页」模板（或手动在 frontmatter 写 `type: collection`），这一页会把
  **同目录（或 `source` 指定目录）下所有笔记的 frontmatter 字段**聚合成视图：
  - **表格视图**：列自动取出现最多的字段（也可用 `columns: 字段1, 字段2` 指定），点列头排序，
    顶部搜索框按名称/路径/字段值筛选，点行打开对应笔记；
  - **看板视图**：按 `groupBy` 字段（默认 `status`）分组，卡片显示名称 + 前两个字段，点卡片打开笔记。
- **可编辑**：点表格单元格直接改字段值（回车保存、Esc 取消，写回该笔记 frontmatter）；
  **看板拖拽**卡片到另一列即改写 `groupBy` 字段；工具栏「+ 新建条目」在数据源目录创建一篇新笔记。
- 视图配置存在页面 frontmatter 里：`type: collection`、`view: table|board`、`groupBy: status`、
  `source: 目录`、`columns: a, b`——都在「页面属性」面板里可改，Obsidian 里看到的就是这些属性和链接。
- 数据由 Host 的 `GET /api/fields?folder=` 提供（只读每篇前 2KB 的 frontmatter，跳过复杂 YAML）。

## 双向链接

- `[[笔记名]]` 渲染为可点击链接（支持 `[[笔记名#标题]]` 跳到指定标题），`![[笔记名]]` 渲染为只读嵌入。
- 每页正文底部有**「链接」区**，**默认折叠**成一行（显示反向链接 / 出链 / 提及的数量），
  点一下展开，展开状态会记住：
  - **反向链接**：哪些笔记链接到了本页（由 Host 扫描整个笔记库，带来源行号，悬停可看原行）；
  - **出链**：本页引用了哪些笔记/嵌入（从块文本提取，自动去重）；
  - 点任一条直接跳转，出链也支持打开不存在的笔记名（会提示找不到）。
- 斜杠菜单 →「双链笔记」：搜索笔记名并选择，自动在当前块插入 `[[笔记名]]`。
- **输入即补全**：在任意块里敲 `[[` 会弹出笔记候选浮层（继续输入按名字过滤），`Enter` / `Tab`
  选第一项、`Esc` 关闭、也可直接点击；选中后自动补成 `[[笔记名]]` 并把光标放到链接后面。
- **未链接提及**：正文里提到某篇笔记的名字但没加链接时，页底「提及」区会列出来（带出现次数），
  点「加链接」把纯文本替换成 `[[笔记名]]`（已有链接和代码块不动）。
- **关系图谱**：`⋯` →「关系图谱」弹出 SVG 图：中心是当前笔记，右侧是它的出链、左侧是反向链接，
  连线表示关系，点任意节点直接打开那篇笔记。

## 视觉

- 所有颜色取自宿主主题 token（`--dsw-alias-*`），浅色 / 深色主题自动适配；强调色用宿主的
  `--dsw-alias-link`（蓝色），hover / 选中用半透明叠层，避免与底色同色而"看不见"。
- 统一圆角（6 / 8 / 12px）、两级阴影（`--nb-shadow-1/2`）与 120–160ms 缓动；菜单、对话框、
  悬浮工具栏带轻微缩放淡入；输入框聚焦有柔和光环。
- 侧栏按目录层级缩进、选中项为柔和强调底色 + 左侧色条；正文行高 1.75，标题 1.875 / 1.4375 /
  1.156em 三级递减，块 hover 有可见底色；空状态重新排版（大标题 + 留白 + 主按钮）。
- 自绘细滚动条、统一选区色、搜索命中柔和高亮。
- **字体**：`⋯` →「字体」面板可选 8 种预设（默认 / Inter / 思源黑体 / 微软雅黑 / 衬线宋体 /
  楷体 / 霞鹜文楷 / 等宽），每项用自身字体渲染预览，面板里也能调字号；还能输入任意
  CSS `font-family` 自定义栈（自动过滤不安全字符）。字体**只作用于正文**，侧栏和菜单保持系统 UI 字体；
  选择会记住。
- **排版向 Notion 靠拢**：正文页宽 720px、行高 1.65；页面标题 40px、正文标题 36 / 24 / 20px 三级阶梯；
  块圆角 4px、待办方框 4px、封面 200px 高。

## 配置

插件行配置在 `cordis.patch.yml`（或插件管理页的配置入口）里：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `vaultPath` | `''` | 笔记库的绝对路径。留空时自动读取 `~/.config/obsidian/obsidian.json` 里当前打开的仓库。 |
| `maxNoteBytes` | 2097152 | 单篇笔记上限，超过时编辑器和 Agent 工具都会拒绝。 |
| `maxIndexFiles` | 5000 | 列出/搜索时最多枚举的 Markdown 文件数，超出会截断并标记。 |
| `templateDir` | `模板` | 新建笔记时把哪个目录里的笔记列为自定义模板。 |
| `attachmentDir` | `附件` | 粘贴图片保存到笔记库里的哪个目录。 |
| `maxAttachmentBytes` | 8388608 | 单张图片上限，超过会被拒绝。 |

## Agent 工具

- `notebook_list` — 列出笔记（可限定子目录）
- `notebook_read` — 按笔记库相对路径读取整篇笔记
- `notebook_search` — 全文检索，返回 `路径:行号: 内容`
- `notebook_write` — 写入笔记，`mode` 为 `replace`（默认）/ `append` / `create`

## 安全边界

- 所有路径在 Host 端归一化，`..`、绝对路径、非 `.md` 文件、`.obsidian` / `.trash` / `.git` 等内部目录一律拒绝；
  写入与读取都做 realpath 校验，符号链接不能把访问带出笔记库。
- HTTP 路由只接受同源请求（校验 `Host` 与 `Origin`，防 DNS rebinding）。
- 写入使用临时文件 + rename 的原子替换；带 `expectedMtimeMs` 保存时，若磁盘上的副本已被外部修改会报冲突而不是覆盖。
- 删除是把笔记移入笔记库的 `.trash/`，不是永久删除；版本快照保留最近 20 个。

## 文件

- `index.js` — Host 半：笔记库服务、`/notebook/api/*` 路由（含附件与历史）、四个 Agent 工具、Config。
- `client.js` — Client 半：`sidebar.panellist` 入口 + `main` 块的 Notion 式页面。
- `cordis.patch.yml` — 插入 Host 行的 bundle patch。
- `locale/{zh,en}.json` — 插件管理页的标题与描述。
